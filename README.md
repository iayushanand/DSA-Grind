# DSA Grind

My personal DSA Solutions from various websites.

---

### Setup: 

1. Clone the repository
```bash
git clone https://github.com/iayushanand/DSA-Grind
```

2. In order to solve a new question run
```bash
starter.bat <filename>
```

3. put your question in question.txt file

4. Solve question in `main.cpp` put inputs in `input.txt` and run using the VSCode shortcut `ctrl + shift + b`

5. Check the output in `output.txt`
